# Запуск Bobogram с телефона: 5 шагов

Нужен только браузер на телефоне и примерно 10 минут. Всё остальное сделает автоматика: создаст таблицы и правила доступа, настроит вход, опубликует серверную функцию для пушей и соберёт сайт.

Всё бесплатно, банковская карта не нужна.

---

## 1. Создать проект Supabase

1. Откройте **<https://supabase.com/dashboard>** и нажмите **Continue with GitHub**. Так не придётся придумывать новый пароль.
2. **New project**:
   - **Name:** `bobogram` (именно так: по этому имени автоматика найдёт проект);
   - **Database Password:** нажмите **Generate a password**. Запоминать его не нужно;
   - **Region:** ближайший к вам, например *Central EU (Frankfurt)*.
3. **Create new project**. Проект создаётся 1–2 минуты. Можно сразу переходить к шагу 2.

## 2. Получить ключ доступа

1. Откройте **<https://supabase.com/dashboard/account/tokens>**.
2. **Generate new token**. Имя любое, например `github`. Срок действия: *Never* (без срока).
3. **Скопируйте токен**: он показывается только один раз.

> Этот токен даёт доступ к вашему аккаунту Supabase. Вставляйте его только в GitHub (шаг 3) и никому не пересылайте.

## 3. Вставить ключ в GitHub

1. Откройте **<https://github.com/bobopsya/bobogram/settings/secrets/actions>**. Если GitHub открылся в приложении, нажмите «⋯» и выберите «Открыть в браузере».
2. **New repository secret**:
   - **Name:** `SUPABASE_ACCESS_TOKEN`
   - **Secret:** вставьте токен из шага 2
3. **Add secret**.

## 4. Включить GitHub Pages

1. Откройте **<https://github.com/bobopsya/bobogram/settings/pages>**.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.

## 5. Опубликовать

1. Откройте pull request с кодом Bobogram: **<https://github.com/bobopsya/bobogram/pulls>**.
2. **Merge pull request → Confirm merge**.
3. Через 3–4 минуты сайт откроется по адресу **<https://bobopsya.github.io/bobogram/>**.

Как идёт публикация, видно на вкладке **Actions**: зелёная галочка значит, что всё готово.

## После запуска

**Зарегистрируйтесь первым.** Первый зарегистрированный пользователь автоматически становится администратором. В меню у него появляется **Админ-панель**: там можно банить, задавать новый пароль тем, кто его забыл, и удалять группы или каналы. Личные переписки админу недоступны.

**Установка на iPhone:**
1. Откройте сайт в **Safari**.
2. **«Поделиться»** (квадрат со стрелкой) → **«На экран Домой»**.
3. Запустите Bobogram с иконки → **Настройки → Включить уведомления**.

Пуш-уведомления на iPhone работают только в установленном так приложении (iOS 16.4+). На Android и ПК установить можно из меню браузера («Установить приложение»).

**Друзьям** достаточно отправить ссылку на сайт. Регистрация — по @имени и паролю, без почты и телефона.

## Если что-то пошло не так

| Что видно | Что делать |
|---|---|
| На сайте «Нужна настройка» | Не добавлен секрет из шага 3. Добавьте его, затем **Actions → Deploy → Run workflow** |
| В Actions красный крестик на шаге *Setup Supabase* | Откройте шаг — в конце написано по-русски, что не так. Чаще всего: проект назван не `bobogram` или ещё создаётся |
| Сайт не открывается (404) | Не выполнен шаг 4. Включите Pages и перезапустите **Actions → Deploy → Run workflow** |
| «Проект на паузе» | Бесплатный проект засыпает после недели без активности. Откройте Supabase → проект → **Restore project** |
| Забыли пароль | Администратор задаёт новый в **Админ-панели** |
| Нет уведомлений на iPhone | Приложение должно быть установлено «На экран Домой», уведомления включены в настройках Bobogram |
| Звонок по мобильному интернету не соединяется | Нужен TURN-сервер (пока не настроен). По Wi-Fi звонки обычно работают |

| Что | Лимит |
|---|---|
| База данных | 500 МБ (это миллионы текстовых сообщений) |

| Серверная функция (пуши) | 500 000 вызовов в месяц |

## Для разработчиков

Нужен Docker.

```bash
npm install
npm run db:start      # локальный Supabase: база, вход, realtime, серверная функция
cp .env.example .env.local   # вставьте ANON_KEY из `npx supabase status`
npm run dev           # http://localhost:5173/bobogram/
```

Проверки:

```bash
npm run lint && npm run typecheck && npm test   # линтер, типы, юнит-тесты
npm run test:db                                 # правила доступа и функции на локальном Supabase
npm run test:e2e                                # сквозные тесты в браузере
```

Где что лежит:
- `supabase/migrations/`: таблицы, правила доступа (RLS), серверные SQL-функции;
- `supabase/functions/bobogram/`: серверная функция (пуши, VAPID-ключи, сброс пароля админом);
- `scripts/supabase-setup.mjs`: автоматическая настройка проекта из GitHub Actions.

Новую миграцию добавляют файлом в `supabase/migrations/`. При следующем деплое она применится автоматически, один раз.
