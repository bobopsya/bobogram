# bobodev — консоль владельца

Python-консоль для отладки и управления Bobogram: статус, техобслуживание, щит от злоупотреблений,
регистрация по приглашениям, баны и спамблоки с причиной и сроком, журнал действий, рассылка.

**Кто может пользоваться:** только владелец и основатели. Кнопка «Скачать bobodev» есть в админке
(вкладка «Статистика») и видна только им; файл отдаёт сервер (`dev_file`), а каждая команда проверяет права
на сервере — у остальных консоль не сработает, даже если у них окажется файл.

**Установка:** нужен Python 3.9+, больше ничего. Скачайте `bobodev.py` из админки (адрес и ключ сервера
уже подставлены) и запустите `python3 bobodev.py` — спросит @имя и пароль. Пароль нигде не сохраняется.
Для скриптов: `BOBODEV_PASSWORD=… python3 bobodev.py -u имя -c "status" -c "logs 10"`.

Команды — `help` внутри консоли. Основные:

| Команда | Что делает |
| --- | --- |
| `status` | пользователи, режимы, блокировки, размер базы, фоновые задачи |
| `maintenance on [--for 30m] [текст]` / `off` | экран «Идут работы» для всех, кроме админов; пуши не шлются |
| `shield on` / `off` | ≤ 20 сообщений за 30 с, автоблок IP на час при 5 новых аккаунтах за 10 минут, ≤ 30 регистраций за 10 минут |
| `signups open\|invite\|closed` | регистрация открыта / по приглашениям / закрыта |
| `invite new [uses] [days]`, `invite list`, `invite revoke` | коды приглашений |
| `user @имя` | профиль, устройства (IP, браузер), причины наказаний |
| `ban @имя [--for 7d] [--no-ip] [--no-device] причина` | бан с причиной и сроком, блокирует IP и устройства |
| `unban @имя`, `spam @имя [--for 1d] причина`, `unspam @имя` | снять бан, спамблок |
| `logs [n]`, `broadcast текст`, `cloudflare`, `ping` | журнал, рассылка, подсказка про DDoS, задержка |

«Щит» защищает приложение от спама и ботов. От сетевого DDoS защищает то, что стоит перед сайтом
(Cloudflare), — команда `cloudflare` подсказывает, как включить.

**Как файл попадает на сервер:** при деплое `scripts/supabase-setup.mjs` кладёт `tools/bobodev/bobodev.py`
в `private.config` (ключ `dev_file:bobodev.py`). Не используйте в файле строку `$bobodev_src$`.
